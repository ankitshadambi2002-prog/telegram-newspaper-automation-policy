# Privacy Policy

**Last updated: November 16, 2026**

## About this project

Telegram Newspaper Automation is a personal project that automates the collection of newspaper PDF files from a public Telegram channel and uploads them to the project owner's Google Drive.

## Information accessed

The automation accesses:
- Telegram account authentication credentials required to access the public channel.
- Newspaper PDF files and related message information, such as publication dates and file names.
- Google Drive access credentials required to upload files.

## How information is used

Information is used only to:
- Find and download selected newspaper PDFs.
- Upload those PDFs to the project owner's Google Drive.
- Track downloaded files and prevent duplicate uploads.

## Storage and security

Authentication credentials are stored as encrypted GitHub Actions secrets and are not intentionally published in the repository.

Downloaded newspaper PDFs are stored in the project owner's Google Drive.

## Third-party services

This project uses Telegram, GitHub Actions and Google Drive. Their respective privacy policies and terms apply to their services.

## Sharing

This project does not sell or intentionally share personal information with third parties for advertising or marketing.

## Contact

For questions about this project or this policy, contact the project owner using the support email listed on the project's Google OAuth consent screen.
